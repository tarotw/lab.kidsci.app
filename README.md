# kidsci.app

科學好好聽 interactive labs, served by GitHub Pages at https://kidsci.app

- `/` — redirects to https://科學好好聽.app
- `/lab/` — lab hub
- `/lab/solar-system/` — 太陽系探索室
- `/lab/taipei-101/` — 台北 101 風雨實驗室
- `/lab/tesla-roadster/` — Roadster 超跑動力實驗室

Add a new lab as `lab/<slug>/index.html` and link it from `lab/index.html`.
