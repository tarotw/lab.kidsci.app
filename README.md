# lab.kidsci.app

科學好好聽 interactive labs, served by GitHub Pages at https://lab.kidsci.app

- `/` — lab hub
- `/solar-system/` — 太陽系探索室
- `/taipei-101/` — 台北 101 風雨實驗室
- `/tesla-roaster/` — Roadster 超跑動力實驗室

Add a new lab as `<slug>/index.html` and link it from `index.html`.

`lab/` keeps a copy of the same pages from the old `kidsci.app/lab/` layout, so existing links under `/lab/` keep working.
